A one-line joke about office life, set in the most familiar meeting in
any office: the daily standup. I arrive with nothing blocking me, then
spend forty minutes proving that the meeting about my blockers is
itself my blocker — and the only action item anyone can think of is to
book another meeting. The punchline is the meeting's own language:
"action item" as a confession that nothing was actually done.

## Run

```sh
node main.ts
```

This writes the joke to `/output/entry.txt` (one line, 152 characters).
Deterministic: every run writes byte-identical output. Node 22+,
standard library only, no network.
